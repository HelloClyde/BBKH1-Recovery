# 验证范围

## 已有实机证据（2026-11-16）

USB BURN 初次端点为 64 字节，预复位后稳定为 512 字节。干净会话完成两份 32 字节状态及 16 KiB 数据读取。随后 0.2.1 已完成系统擦除、底层系统及约 915.9 MiB 文件输出，在恢复用户资料时复现日期异常。

只读检查确认 Windows 压缩/禁止索引标志使属性 `0x2810/0x2820` 输出为四位，破坏固定字段。保留两份用户文件后，使用仅针对该次备份的续接工具补回文件并发送官方结束命令。用户确认 H1 正常进入系统桌面。续接没有再次擦除或写入系统固件。

**0.2.2 日期修正合入后，未再从头完整擦写 H1。** 上述恢复不能表述为新版单次完整实机验收。原始用户文件、私人续接数据及日志不公开；公开摘要见 `hardware-validation.json`。

## 离线验证

- 43 项假 WinUSB 传输回归，以及独立只读回归。
- 4 项首次枚举/预复位场景，包括失败时停止接入。
- 6 项属性补丁检查，包括内存保护还原及签名不匹配时不改代码。
- 24 项 x86 指令检查，核对低八位、寄存器、堆栈、标志及日期字段位置。
- x86 导出 ABI 和假后端无硬件 API 的导入检查。
- libwdi CLI 的帮助及中文参数转换检查。
- 9 项一键准备/启动检查：无害替身、错误拦截、重复启动保护和真实准备程序 `--files-only`。

开发时还在官方原程序内验证了两处指令匹配与修正；该专用验证 DLL 在创建 USB 注册前拒绝全部初始化，并编译禁用传输。该结果不作为 CI 刷机结果。

CI 运行这些主机测试，不连接设备、不安装驱动、不执行官方恢复程序。构建/包校验通过不代表物理 USB、UAC 或完整恢复验收通过。没有用其他设备或模拟图代替 H1 实机证据；可公开的干净运行截图仍待补充。
