H1 V1.41 超级系统恢复的 Windows 10 x64 兼容版本首次开源发布。

普通用户下载 `H1-V1.41-Win10x64-v0.2.2-complete.zip`，完整解压后运行“启动恢复.cmd”。驱动准备、当前目录部署和官方恢复启动由入口完成。原包单独归档于 `official-v1.41` Release；本版本的完整包由 Actions 下载原包并合入源码编译产物生成。

包含 WinUSB x86 ABI 桥接、首次 BURN 稳定枚举修正、备份属性导致的日期异常修正，以及一键准备程序、离线测试、构建源码与第三方来源说明。用户备份和本机日志不包含在发布资产内。

验证边界：已有 H1 完成“0.2.1 系统写入＋用户文件续接”并正常启动；0.2.2 的日期修正经过离线及禁用 USB 的原程序内检查，尚未再次从头完成整轮实机恢复。因此此版标为预发布。CI 只运行主机测试，不装驱动或刷机。
