H1 V1.41 超级系统恢复的 Windows 10 x64 兼容版本开源整合包。

普通用户下载 `H1-V1.41-Win10x64-v0.2.3-complete.zip`，全部解压后运行“启动恢复.cmd”。官方原包另放在 `official-v1.41` Release；本版全部成品由这次 Actions 构建、测试、整合和上传。

0.2.3 修复英文 Windows 构建环境无法解码官方 RAR 中文文件名的问题：显式按 CP936 解码，流式提取到 ASCII 文件名，并核对内部安装程序哈希，再解包原始恢复内容。兼容 DLL 保持已校验的 0.2.2，修正 Win10 x64 驱动、首次 BURN 通信和备份属性引起的日期异常。

包含完整包、兼容层包、带固定 libwdi 的源码包、离线验证记录与 SHA256SUMS.txt。源码和构建脚本采用 GPL-3.0-or-later；官方程序及第三方组件保持原许可。

验证边界：已有 H1 完成“0.2.1 系统写入＋用户文件续接”并正常启动。0.2.2 日期修正已通过离线及禁用 USB 的原程序内检查，尚未再次从头完成整轮实机恢复；0.2.3 只调整构建整合。因此此版标为预发布。CI 不安装驱动、不刷机。用户备份、私人续接数据和本机日志未公开。
